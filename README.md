# Pärnu 3D — симуляция города Пярну (Эстония)

Интерактивная 3D-копия города Пярну, построенная из **реальных данных OpenStreetMap**:
11 198 зданий, 5 485 улиц и дорог, река Пярну, Пярнуский залив, пляж, парки
и 282 реальные точки интереса (бары, клубы, рестораны, школы, отели, спа…).

## Запуск

Нужен любой статический веб-сервер (из-за загрузки данных браузером):

```bash
cd Simulation-city
python3 -m http.server 8000
# открыть http://localhost:8000
```

или `npx serve .` — затем открыть адрес в браузере. Интернет не нужен:
three.js и данные города лежат в репозитории.

## Возможности

- **Время течёт**: выбор любой даты и времени, скорости от паузы до «2 часа в секунду».
- **Солнце по астрономии**: высота/азимут считаются по реальным формулам для широты
  Пярну — летом белые ночи, зимой солнце едва поднимается. Рассветы, закаты, звёзды.
- **Сезоны** (по выбранной дате): зимой город и залив под снегом и льдом, осенью
  жёлтые кроны, летом зелень.
- **Погода**: авто-режим (вероятности зависят от сезона) или вручную — ясно, облачно,
  дождь, снег. Осадки согласованы с температурой.
- **Жители** ходят по реальной уличной сети и выбирают цели по расписанию:
  - ночью в пятницу/субботу — **толпы у баров и клубов** старого города;
  - утром в будни — у школ и детских садов;
  - летним днём — **пляж**, особенно в ясную погоду в выходные;
  - обед — кафе и рестораны, вечер — рестораны, театр, парки.
- **Машины** ездят по дорогам с фарами и габаритными огнями, трафик зависит от часа
  (утренние и вечерние пики).
- **Ночь**: окна домов, уличные фонари, звёзды, луна и неоновая подсветка
  заведений (бары — розовым, рестораны — оранжевым, отели — голубым).
- **Тени от солнца** — движутся с течением времени, длинные на закате
  (переключатель в панели).
- **Лодки** у пяти реальных гаваней Пярну и парусные яхты в заливе
  (зимой залив замерзает — лодки убираются).
- **Подписи 208 реальных заведений** из OSM при приближении камеры.
- **Кнопки сцен**: «Сейчас», «Пт · бары», «Пляж», «Зима» — плавный перелёт камеры
  к нужной дате, погоде и месту.
- **Миникарта** с маркером камеры; клик — перелёт в выбранный район.
- Адаптивное качество рендера по FPS.

## Управление

| Действие | Управление |
|---|---|
| Вращение камеры | ЛКМ + движение мыши |
| Сдвиг | ПКМ (или Shift+ЛКМ) |
| Масштаб | колесо мыши / Q, E |
| Полёт | W A S D / стрелки |

## Структура

- `index.html` — страница и панель управления
- `js/main.js` — рендер (three.js), солнце, погода, сезоны, симуляция жителей и машин
- `data/parnu.js` — компактные данные города (метры от центра Пярну, 58.3859° N 24.4971° E)
- `tools/convert.py` + `tools/q_*.txt` — запросы Overpass API и конвертер для
  регенерации данных (`python3 tools/convert.py` после скачивания свежих JSON)
- `vendor/three.min.js` — three.js r147
