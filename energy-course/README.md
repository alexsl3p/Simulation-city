# ⚡ Энергия — интерактивный курс с нуля до PhD

Веб-курс по физике энергии для тех, кто **начинает с нуля**: как работает энергия,
как она получается и передаётся — и как придумывать способы получать её эффективнее
и по-новому. Простым языком, с интерактивными моделями и тестами.

## Запуск

Это статический сайт без сборки. Откройте `index.html` напрямую в браузере
или поднимите любой статический сервер:

```bash
cd energy-course
python3 -m http.server 8000
# открыть http://localhost:8000
```

Интернет и зависимости не нужны — всё работает офлайн.

## Что внутри

- **10 модулей, 43 урока** — от «что такое энергия» до термоядерного синтеза,
  квантовой физики и методологии изобретательства в энергетике.
- **«Главное простыми словами»** — врезка с сутью урока в одну фразу в самом верху
  каждого урока: новичок схватывает ядро за пару секунд ещё до чтения.
- **Словарь терминов** (44 термина) с живым поиском — застряли на слове, нашли объяснение.
- **Схемы устройств** «из чего состоит и как работает по шагам» — ТЭС, солнечная панель,
  ядерный реактор, ветряк, ГЭС, литий-ионный аккумулятор, токамак.
- **Встроенный ИИ-преподаватель** (Claude) — задавайте вопросы по уроку как преподавателю.
  Работает через ваш личный ключ Anthropic API (прямой вызов из браузера,
  `anthropic-dangerous-direct-browser-access`; ключ хранится только локально).
  Без ключа — кнопка открывает вопрос в claude.ai.
- **7 интерактивных моделей** (canvas): маятник (сохранение энергии), газ и энтропия,
  тепловая машина и цикл Карно, электрическая цепь (закон Ома), генератор (индукция),
  E=mc², солнечная панель.
- **Тест после каждого урока** (92 вопроса) с разбором ответов.
- **Прогресс** сохраняется в браузере (localStorage).
- **Адаптивный дизайн** — телефон и десктоп.

## Структура файлов

- `index.html` — каркас страницы
- `css/style.css` — оформление (тёмная тема, адаптив)
- `js/content.js` — вся учебная программа (модули, уроки, формулы, тесты)
- `js/sims.js` — интерактивные модели на canvas
- `js/app.js` — навигация, рендер уроков, тесты, прогресс
- `test-ux.mjs` — автотест UX в браузере (Playwright): `node test-ux.mjs`

## Как добавить урок

В `js/content.js` найдите нужный модуль и добавьте объект урока в массив `lessons`.
Блоки урока: `text`, `formula`, `callout` (kind: idea/warn/key), `try`, `sim`.
Новую интерактивную модель добавьте в `js/sims.js` как `SIMS.имя = function(container){…}`
и сошлитесь на неё блоком `{ t:'sim', sim:'имя' }`.
